## Шаги внутри блока

Это ориентир: порядок и техническую реализацию владелец выбирает сам. Дополнительное согласование обычных решений не требуется.

1. Хранить минимально нужное состояние: конфигурация, сопоставимая валидация, метрика, время и ссылка на лучший артефакт. Памяти/короткого JSON достаточно; большой отчёт или база экспериментов не нужны.

2. Связать следующий запуск с гипотезой LLM по результатам прошлого. Доступные модели, признаки, обработку или схему оценки агент выбирает через поддержанные инструменты.

3. Ограничить весь запуск до 3 часов с запасом на финальное обучение/ответ. Сначала сохранить корректный ранний результат; новая ошибка/худший вариант не должны его уничтожить.

4. Проверить полный цикл на сокращённом бюджете и корректную остановку. Минимальное число итераций организаторами не задано; обоснованная остановка после одного эксперимента допустима.

5. При доступном usage учитывать расход токенов, ограничивать объём контекста и повторы. Передать Егору версию с завершённой исследовательской логикой для следующего проверенного кандидата.
