## Шаги внутри блока

Это ориентир: порядок и техническую реализацию владелец выбирает сам. Дополнительное согласование обычных решений не требуется.

1. Принять доступ, получить код/CSV и подготовить отдельное окружение. До получения команд можно проверить комплект файлов; не ждать отдельного поручения на каждый шаг.

2. По готовности инструкции Егора повторить установку. По готовности версии Ивана/Юры выполнить обе общие команды с коротким бюджетом. Любой блокер сразу записать в карточке, указав команду и ошибку.

3. Проверить путь ответа, строки/ID/колонки, допустимые классы и числовые значения готовым валидатором. Слова «всё работает» заменить версией, командой, кодом завершения и фактическим результатом.

4. Ошибки адресовать владельцу компонента, затем самостоятельно повторить исправленный сценарий. Отчёт — один комментарий/список багов; отдельный шаблонный документ не обязателен.
