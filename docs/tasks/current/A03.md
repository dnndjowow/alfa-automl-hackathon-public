## Шаги внутри блока

Это ориентир: порядок и техническую реализацию владелец выбирает сам. Дополнительное согласование обычных решений не требуется.

1. Проверить принятие приглашений, доступ к CSV и выданному API. Передать каждому ссылку на его блок; проблемы фиксировать в его карточке, без отдельного STATUS-реестра.

2. Проверить Python 3.12 и официальный requirements, минимальный вызов API с Иваном. Разобрать несовпадение mcp в baseline/requirements до первой отправки. Подтверждённый запуск платформы: python3 solution.py task.md из каталога задачи; совместимость собственных импортов проверить из ZIP.

3. Подготовить сборку корневых solution.py, нужных .py и официального requirements.txt в ZIP до 100 МБ, даже если загрузчик показывает 128 МБ. Вложенные папки, конфиги и .whl не копируются; pip из решения недоступен. Не включать данные, модели, ключи и кэши.

4. Записать рабочие команды подготовки/сборки в одном месте. Если полного solution.py ещё нет, отдельно отметить, что пока проверены только окружение и состав архива. Максиму передать готовые команды по мере появления.
