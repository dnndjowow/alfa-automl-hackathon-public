## Шаги внутри блока

Это ориентир: порядок и техническую реализацию владелец выбирает сам. Дополнительное согласование обычных решений не требуется.

1. Проверить комплект CSV по существующему DATA_SETUP и скачать файлы. Исправить конкретную нерабочую ссылку/путь в текущей инструкции, если найдено; второй каталог материалов не нужен.

2. Для регрессии посчитать размеры, типы, пропуски, категории, квантили цели и различия train/test. Проверить year_built=0/пропуски и смысл Year_Factor; ID не считать ID здания без подтверждения.

3. Для классификации посчитать доли всех классов, новые категории proto/service/state, пропуски и дубликаты. service="-" имеет отдельный смысл; исключённая label была утечкой.

4. Передать 5–10 наблюдений в комментарии карточки или одном коротком DATA_REPORT. Код/команда должны воспроизводить числа; гипотезы подписывать. Графики делать только если они помогают выбору.

5. Передавать полезные факты сразу по мере получения. Анализ не блокирует pipeline Юры; параметры моделей и обработку он выбирает самостоятельно с учётом фактов.
