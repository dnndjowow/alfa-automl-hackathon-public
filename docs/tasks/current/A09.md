## Шаги внутри блока

Это ориентир: порядок и техническую реализацию владелец выбирает сам. Дополнительное согласование обычных решений не требуется.

1. На локальных копиях предоставленных материалов подготовить 2–3 согласованных варианта: другой каталог, другое имя цели, перестановка колонок или неизвестная категория. Обновить соответствующее описание, чтобы задача оставалась непротиворечивой.

2. Выполнить готовую команду агента и проверить ожидаемый путь/схему ответа. Сначала использовать сокращённый бюджет и небольшие копии; реальные private-метрики этими проверками не заменяются.

3. Для каждого сбоя приложить команду, изменённые входы, ожидаемый/фактический результат и версию. Не создавать отдельную презентацию, матрицу соответствия или большой отчёт.

4. Передать Ивану и Юре воспроизводимые случаи. Дополнить README конкретной недостающей командой только при обнаружении такой проблемы.
