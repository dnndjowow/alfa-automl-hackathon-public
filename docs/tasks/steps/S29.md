## Что делать по шагам

1. На основе истории просить LLM выбрать следующую конфигурацию модели/признаков/обработки либо остановиться.

2. Проверять параметры и выполнить хотя бы один реальный цикл решение → эксперимент → анализ.

3. Ввести общий дедлайн запуска с запасом на финальное обучение/запись; ограничить отдельные эксперименты и повторы.

4. Проверить остановку на сокращённом бюджете и успешное сохранение лучшего ответа. Число итераций определять бюджетом, а не выдуманным минимумом.

## Готово, когда

- [ ] Новый эксперимент связан с анализом предыдущего результата LLM.
- [ ] Сокращённый бюджет приводит к валидному ответу и понятной причине остановки.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
