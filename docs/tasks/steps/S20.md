## Что делать по шагам

1. Выбрать с Иваном минимальную модель из разрешённых зависимостей, сначала с небольшим бюджетом.

2. Соединить загрузку, преобразования и split; обучить модель и посчитать RMSE.

3. Вернуть результат по контракту, время и путь к артефакту; ограничить CPU и параметры запуска.

4. Проверить конечность предсказаний, сохранить команду и фактический результат.

## Готово, когда

- [ ] Есть реальный RMSE, коммит и команда повторения.
- [ ] Модель выдаёт предсказания нужной длины и не требует ручной правки данных.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
