## Что делать по шагам

1. Взять точный коммит и готовые команды Юры; запустить каждую с согласованным коротким бюджетом.

2. Проверить путь submission.csv, колонки, число/порядок ID, отсутствие пустых предсказаний и допустимые классы.

3. Записать длительность, код завершения и проверенный вывод; ошибки оформить отдельно с шагами повторения.

4. Передать баги PM и назначенному разработчику. Первый сабмит PM может выполнять параллельно с этой проверкой.

## Готово, когда

- [ ] Есть два реальных результата со ссылками на версию/логи.
- [ ] Каждый найденный баг содержит точную команду и ожидаемый результат.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
