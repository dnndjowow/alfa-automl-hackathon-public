## Что делать по шагам

1. Выписать обязательные требования: роль LLM, AutoResearch, ресурсы, формат запуска, архив, ответ и разрешённые источники.

2. Для каждого найти файл, команду или лог текущей реализации; если доказательства нет — написать «не проверено».

3. Сверить FAQ и закреплённые материалы на предмет уточнений; добавлять точную ссылку и дату, без самостоятельной смены технических правил.

4. Передать PM список пробелов, Ивану — технические вопросы. Обновлять подтверждённые пункты после исправлений.

## Готово, когда

- [ ] Каждый статус подтверждён конкретным источником/артефактом.
- [ ] Пробелы превращены в короткий список для PM, новые требования не выдуманы.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
