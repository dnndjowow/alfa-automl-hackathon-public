## Что делать по шагам

1. Использовать согласованную минимальную модель, те же соглашения результата и допустимый CPU-бюджет.

2. Обучить на stratified split; вернуть строковые классы, корректно восстановив отображение меток.

3. Посчитать Macro F1 и показать метрики редких классов для диагностики.

4. Обработать ошибку обучения и приложить команду, длительность и фактический результат.

## Готово, когда

- [ ] Получен конечный Macro F1 и допустимые строковые классы.
- [ ] Контракт совпадает с регрессией, инструмент доступен контроллеру.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
