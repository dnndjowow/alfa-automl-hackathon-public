## Что делать по шагам

1. Для каждого запуска сохранять конфигурацию, split/seed, метрику, направление, время, ошибку и путь к результату.

2. Сравнивать только сопоставимые результаты; новый лучший артефакт фиксировать после проверки.

3. Проверить, что неудачный или худший эксперимент не затирает предыдущий лучший.

4. Передавать LLM компактную историю без больших данных и секретов.

## Готово, когда

- [ ] Лучший результат воспроизводим по журналу.
- [ ] Падение следующей попытки сохраняет прошлую валидную модель/ответ.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
