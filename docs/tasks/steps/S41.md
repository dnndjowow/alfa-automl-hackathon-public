## Что делать по шагам

1. Получить архив и SHA выбранной версии у PM; проверить имя, размер и список файлов.

2. Убедиться, что solution.py, официальный requirements.txt и нужные .py находятся в корне.

3. Проверить отсутствие ключей, данных, моделей, кэшей, .venv и зависимости от вложенных файлов, которые платформа не копирует.

4. Сверить команды из README с RUNBOOK, передать PM найденные несоответствия. Не помечать полный запуск успешным по одному списку файлов.

## Готово, когда

- [ ] Есть фактический список/хеш архива и отмеченные пункты.
- [ ] PM проверил все найденные несоответствия до отправки.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
