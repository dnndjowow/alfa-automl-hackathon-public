## Что делать по шагам

1. Открыть README, личную вкладку, DATA_SETUP и ссылки на файлы. Зафиксировать конкретные недоступные материалы.

2. Подготовить поля: дата МСК, коммит, окружение, команда, ожидание, фактический вывод, код завершения, длительность, ссылка на лог.

3. Добавить шаблон бага: как повторить, ожидаемое/фактическое поведение, серьёзность, кто исправляет.

4. Сообщить PM о доступности. До готового окружения не менять ML-код и не придумывать успешные результаты.

## Готово, когда

- [ ] Есть шаблон, пригодный для фактических проверок.
- [ ] Недоступность ссылок описана без секретов.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
