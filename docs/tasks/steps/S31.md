## Что делать по шагам

1. Согласовать с Иваном сценарии невалидных параметров, ошибки обучения, сетевого сбоя и исчерпания времени.

2. Воспроизвести их на небольшом запуске: ограниченные повторы, понятный статус, отсутствие бесконечного ожидания.

3. Проверить, что уже сохранённый валидный submission не повреждён и худший результат его не заменил.

4. Исправить найденные ошибки и передать Максиму команды для повторения.

## Готово, когда

- [ ] Есть реальные проверки минимум трёх сбоев.
- [ ] Валидный предыдущий результат остаётся доступен; известные ограничения записаны.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
