## Что делать по шагам

1. Сравнить baseline и 1–2 осмысленных варианта, включая обработку дисбаланса при подтверждённой пользе.

2. Держать split/seed одинаковыми; оценивать Macro F1, отдельно смотреть редкие классы и время.

3. Сохранить лучший вариант и сверить итоговый вывод с допустимыми строковыми классами.

4. Подготовить кандидата на утренний выбор; закончить новые эксперименты к 23:00.

## Готово, когда

- [ ] Есть реальное сравнение на одной валидации.
- [ ] Лучшая конфигурация и ограничения записаны; поздний эксперимент не уничтожает рабочую версию.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
