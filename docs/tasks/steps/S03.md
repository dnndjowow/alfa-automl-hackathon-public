## Что делать по шагам

1. Открыть порядок выполнения, дать каждому ссылку на его первую карточку; получить подтверждение ближайшего результата.

2. Проверить у Ивана и Юры доступ к коду, данным и выданному API. Логины остальных собрать для приглашения; не ждать их для планирования.

3. Зафиксировать старт 23.10 20:00, финал 25.10 20:00 МСК и внутренние контрольные точки. Ключи передать защищённо, в Issues их не писать.

4. Создать docs/STATUS.md: участник, текущая карточка, следующий результат, блокер. При отсутствии доступа указать владельца решения.

## Готово, когда

- [ ] У каждого есть первая карточка и понятный способ получить материалы.
- [ ] В STATUS нет ключей; доступ к API передан тому, кто подключает LLM.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
