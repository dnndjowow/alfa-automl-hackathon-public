## Что делать по шагам

1. Использовать ключ/модель/base URL из выданного окружения; выполнить минимальный реальный запрос.

2. Попросить модель вернуть структурированное описание следующего действия; проверить JSON и разрешённые значения.

3. Добавить таймаут запроса, ограниченный retry и понятную обработку обрезанного/пустого ответа.

4. Сохранить обезличенный пример запроса/решения; ключи и полный env в логи не выводить.

## Готово, когда

- [ ] Есть реальный ответ выданной модели и результат его валидации.
- [ ] Невалидный ответ не вызывает бесконечный цикл.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
