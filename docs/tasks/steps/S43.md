## Что делать по шагам

1. Посмотреть полный прогон, метрики, время, ответы и журнал ошибок; подтвердить реальное участие LLM и исследовательский цикл.

2. Сверить ограничения private-части, зависимости и фактическую версию архива.

3. При существенном непроверенном изменении выбрать резерв; блокирующие исправления принимать только с проверкой.

4. До 17:00 подтвердить PM точный SHA/архив и остаточные ограничения.

## Готово, когда

- [ ] Есть явное техническое решение и выбранный архив.
- [ ] Результат связан с конкретной проверенной версией.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
