## Что делать по шагам

1. Получить версию S22/S24, собрать ZIP и повторить проверку состава/импортов/выходных файлов.

2. Подтвердить с Иваном, что LLM реально участвует и локальные команды отрабатывают.

3. Отправить архив на платформу до 15:00 МСК; записать коммит, имя, хеш архива, время, статус и расход попытки.

4. Проверять результат и очередь по контрольным точкам; ошибки направлять владельцу. Не ждать полного исследования ради первой отправки.

## Готово, когда

- [ ] Есть подтверждение загрузки и запись в SUBMISSIONS.
- [ ] Сохранена локальная копия рабочего архива и понятен статус платформы.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».

Пути ожидаемых новых отчётов в карточке — результат задачи, а не обещание, что файлы уже существуют. Секреты и CSV в Git не добавлять.
