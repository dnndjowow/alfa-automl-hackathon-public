## Что делать по шагам

1. Вместе с Иваном подключить генератор ответа к контроллеру и рабочим моделям.

2. Проверить оба запуска с небольшим бюджетом, включая запуск из другого текущего каталога.

3. Обновить RUNBOOK фактическими командами и измеренными результатами; зафиксировать commit SHA.

4. Передать PM и Максиму готовую версию, команды, ожидаемые файлы и известные ограничения.

## Готово, когда

- [ ] Обе команды завершаются корректным файлом ответа.
- [ ] PM получает воспроизводимую версию к 14:00, улучшения идут после неё.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
