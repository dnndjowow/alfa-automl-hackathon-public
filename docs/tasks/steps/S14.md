## Что делать по шагам

1. Получить от PM готовые команды и версию; повторить установку в отдельном окружении.

2. Проверить чтение обоих task.md и CSV. Секреты вводить локально, не вставлять в отчёт.

3. Для каждого сбоя сохранить точную команду, код завершения и фрагмент лога; не исправлять молча инструкции.

4. Обновить QA_LOG: что проверено, что невозможно до готовности solution.py, кому передан блокер.

## Готово, когда

- [ ] Отчёт содержит фактический результат установки/чтения данных.
- [ ] Неуспешные команды можно повторить по описанию.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
