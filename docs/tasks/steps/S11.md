## Что делать по шагам

1. Описать инструменты загрузки, обучения, оценки и предсказания по контракту. Сначала использовать небольшие заглушки.

2. Связать ответ LLM с реальным диспетчером вызовов: входные параметры проверяются до исполнения.

3. Вернуть модели результат инструмента; обработать ошибку инструмента и запрещённое действие.

4. Показать цепочку описание → решение → вызов → результат. Согласовать с Юрой точки подключения.

## Готово, когда

- [ ] Решение LLM реально меняет вызванный инструмент/параметры.
- [ ] Лог показывает минимум одну полную цепочку без секретов.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
