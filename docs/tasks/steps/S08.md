## Что делать по шагам

1. Прочитать условие и словарь; запустить скрипт с shape, типами, пропусками, дубликатами ID и кардинальностью категорий.

2. Посчитать квантили site_eui, долю крайних значений и распределения основных категорий. Построить 2–3 полезных графика, если они проясняют вывод.

3. Сравнить train/test: новые категории, доли пропусков, диапазоны числовых признаков. Отдельно проверить year_built=0 и energy_star_rating.

4. Отделить измерения от гипотез. Не вычитать Year_Factor из year_built; не считать id постоянным ID здания без доказательства. Передать 3–5 наблюдений Ивану.

## Готово, когда

- [ ] Числа получены фактическим запуском; код и команда приложены.
- [ ] Есть риск утечки/сдвига и краткий список вопросов, а не необоснованный рецепт модели.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
