## Что делать по шагам

1. Взять имена колонок и форму результата из условия/образца; не копировать образец как предсказания.

2. Вернуть ID в исходном порядке; проверить длину, колонки, классы и отсутствие NaN/inf.

3. Сохранять рядом с task.md через временный файл и надёжную замену завершённого результата.

4. Показать успешную проверку обоих ответов и отклонение файла с неправильной длиной/колонкой.

## Готово, когда

- [ ] Оба публичных submission соответствуют схеме и порядку test.
- [ ] Некорректный новый файл не заменяет уже валидный.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
