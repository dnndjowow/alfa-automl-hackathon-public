## Что делать по шагам

1. Скачать данные по инструкции; начать чтение CSV, пока Иван фиксирует контракт. После 21:00 сверить интерфейс с I1.

2. Разрешать пути относительно task.md, а не текущего каталога. Разделить train/test/словарь/образец ответа.

3. Сохранить ID и порядок test отдельно; проверить наличие колонок, дубликаты ID и несовпадение признаков.

4. Выполнить загрузку обеих задач, записать фактические размеры и команды в PR.

## Готово, когда

- [ ] Обе папки читаются из другого текущего каталога.
- [ ] ID и число строк test сохранены без переупорядочивания.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
