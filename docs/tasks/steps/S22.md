## Что делать по шагам

1. Заменить заглушки инструментами Юры; проверить типы входов/выходов на реальных данных.

2. Дать LLM профиль и описание; убедиться, что выбранные ею параметры используются в запуске.

3. Вместе с Юрой пройти обе публичные задачи сокращённым бюджетом, записать решения и вызовы.

4. При ошибке показать причину и сохранить уже готовые артефакты; зафиксировать общую команду solution.py.

## Готово, когда

- [ ] Логи содержат реальные решения модели и фактические вызовы ML.
- [ ] Общий запуск обеих задач не требует ручной смены цели/метрики.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
