## Что делать по шагам

1. Описать маппинг модулей репозитория в корень ZIP: solution.py, необходимые .py и актуальный requirements.txt.

2. Сделать сборку без данных, моделей, ключей, .venv, Git и кэшей. Проверить размер до 100 МБ.

3. Извлечь архив во временный каталог и проверить список файлов/импорты; пока solution.py не готов, явно отметить непроверенный полный запуск.

4. Записать команду сборки, проверки и будущего запуска в RUNBOOK.

## Готово, когда

- [ ] Все нужные .py размещаются в корне; зависимости соответствуют официальным.
- [ ] Сборка воспроизводима; отсутствие реализации не маскируется как успешный запуск.
- [ ] Приложены ссылка на коммит/отчёт, точная команда проверки, фактический результат и ограничения. Статус «На проверке»; после приёмки — «Готово».
