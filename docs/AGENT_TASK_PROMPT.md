# Передача карточки агенту

Сначала открыть свой Issue и скопировать его полностью. Затем добавить этот контекст, заменив номер, владельца и ближайший результат.

```text
Работаем над автономным ML-агентом на хакатоне Альфа.
Репозиторий: https://github.com/selecteg12/alfa-automl-hackathon
Моя задача: #N. Ответственный: имя.
Ближайший проверяемый результат: ...
Согласованный срок: ... МСК.

Прочитай README.md, AGENTS.md, docs/MATERIALS.md и полный текст Issue ниже.
Проверь доступность нужного кода, task.md и CSV.
Если материалы недоступны, перечисли конкретно что отсутствует и продолжай
независимую часть задачи; не выдумывай содержание файлов.

Выполни пошаговый план в пределах задачи и согласованного интерфейса.
Поддерживай работу на новых задачах, ограничения платформы и сохранение
раннего корректного результата.

В конце сообщи:
1. Что изменено и где.
2. Какую команду реально запустил.
3. Фактический результат проверки.
4. Какие ограничения и блокеры остались.
5. Что передать следующему участнику.

Полный текст Issue:
...
```

## Что делает человек

- Подтверждает область задачи и интерфейс с Иваном.
- Проверяет, что агент работает с нужной версией кода.
- Просматривает изменения и повторяет основную команду.
- Передаёт проверенный результат, а не только ответ агента.
- Секреты передаёт через локальное окружение; в Issue, PR и промпты общего доступа их не вставляет.
