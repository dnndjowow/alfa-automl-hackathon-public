## Регрессия: что важно

- Таргет оценивается в исходных единицах kBtu/ft² за год. После log-преобразования нужно вернуть предсказания в исходную шкалу перед RMSE.
- Погода уже известна за тот же год. Это оценка при известных характеристиках и погоде, а не прогноз до начала года.
- Year_Factor — анонимизированный код периода; year_built — календарный год постройки. Вычитание одного из другого не даёт возраст здания.
- id — идентификатор строки; его постоянство для одного здания между годами не подтверждено.
- В year_built встречаются нули и пропуски, в energy_star_rating — пропуски.
- sample_submission содержит нули как пример формы. Они не являются ответами.

## Классификация: что важно

Классы: Normal, Generic, Exploits, Fuzzers, DoS, Reconnaissance, Analysis, Backdoor, Shellcode, Worms.

- Классы несбалансированы. Условие отдельно отмечает редкие Worms, Shellcode и Analysis.
- Основная метрика — f1_score(..., average="macro"). Accuracy и Weighted F1 вспомогательные.
- Категориальные признаки: proto, service, state. Значение '-' в service означает отсутствие определённого сервиса.
- Бинарная label удалена из данных как утечка для определения типа атаки. Не искать и не восстанавливать её из внешних ответов.
- Для каждого id требуется строковая метка класса, не её числовой код.
- Пропуски, неизвестные классы, дубликаты id и перестановка строк в ответе недопустимы.

## Метрика для тех, кто не занимается ML

**Validation** — часть train, которую временно не показывают модели при обучении и используют для оценки. Ответы test команде неизвестны.

**RMSE** показывает величину ошибки регрессии и сильнее учитывает большие отклонения. Меньшая цифра означает лучшее качество на том же разбиении.

**Macro F1** считает F1 по каждому классу и усредняет их с равным весом. Поэтому успех на частых классах не заменяет качество на редких.

Локальная метрика помогает сравнивать эксперименты. Она не равна public score: платформа использует скрытые ответы и нормирование относительно своего baseline.
