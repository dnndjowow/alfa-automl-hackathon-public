## 1. Репозиторий

Открыть репозиторий → Settings → Collaborators → Add people. Ввести точный GitHub-логин каждого участника, проверить аккаунт и отправить приглашение. Участник принимает приглашение под своим аккаунтом.

У личного приватного репозитория есть владелец и collaborators. Collaborator получает чтение и запись; отдельной роли только для чтения здесь нет. Для тонких ролей нужна организация, но для этого хакатона отдельную организацию не требуется создавать.

## 2. Доска Projects

Открыть доску → меню … → Settings → Manage access → Invite collaborators. Выдать Write для работы с карточками. Владелец сохраняет Admin.

Доступ к Project не даёт доступ к приватному репозиторию. Для просмотра и редактирования его задач нужны оба доступа.

## 3. Назначение задач

После принятия приглашения GitHub разрешает назначение Assignee. Имя/логин указаны в таблице; метки owner:* сохраняются, поскольку по ним настроены личные вкладки. Ответственность не меняется, пока человек принимает приглашение.

## Проверка

Попросить каждого открыть README, свой Issue и доску, затем подтвердить, что он может менять нужную карточку.
