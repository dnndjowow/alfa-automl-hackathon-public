# Старт участника

1. Принять приглашение в [репозиторий](https://github.com/selecteg12/alfa-automl-hackathon) под своим GitHub-аккаунтом. Доступ к доске выдан отдельно; логины — в [ACCESS](ACCESS.md).
2. Открыть свою [вводную](TEAM_CONTEXT.md), затем первый блок Axx в [маршруте](EXECUTION_ORDER.md). Старые Sxx/обзорные этапы заменены, повторно их выполнять не нужно.
3. Получить код, прочитать README/AGENTS и конкретный блок. CSV расположить по [DATA_SETUP](DATA_SETUP.md); исходные материалы находятся в reference/. Будущие функции/файлы в карточках ещё предстоит создать.
4. Отметить блок «В работе», подтвердить доступность входов и начать. Реализацию выбрать самостоятельно в ограничениях кейса.
5. Своему агенту передать вводную, карточку, доступ к актуальному коду/данным. Запрос сформулировать самостоятельно; агент не обязательно видит браузер/Drive/локальные CSV.
6. На контрольной точке дать ссылку на реальный результат и проверку. Блокер сообщить сразу, продолжая независимую часть. После проверки закрыть блок; дополнительные отчёты не нужны.

Локальный код:

```text
git clone https://github.com/selecteg12/alfa-automl-hackathon.git
cd alfa-automl-hackathon
```
