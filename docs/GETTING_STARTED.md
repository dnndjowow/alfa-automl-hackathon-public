# Старт для участника команды

## 1. Получить доступ

Когда PM пригласит твой GitHub-аккаунт, принять приглашение. Нужен доступ и к приватному репозиторию, и к Project. Инструкция для PM: [ACCESS.md](ACCESS.md).

## 2. Найти свою задачу

Открыть [доску](https://github.com/users/selecteg12/projects/2) или [порядок выполнения](EXECUTION_ORDER.md). На доске есть отдельная вкладка для каждого участника и «Порядок выполнения». Владельцы сейчас указаны именами в поле «Ответственный», заголовках и метках owner:*.

В 20:00 23 октября: Иван — S01, Юра — S02, Егор — S03, Артём — S04, Максим — S05. Прямые ссылки и личная последовательность находятся в [маршруте](EXECUTION_ORDER.md). Открывать рабочие Sxx; #1–12 — обзорные этапы, повторно их выполнять не нужно.

## 3. Открыть код и материалы

Если работаешь через локальный Git:

```text
git clone https://github.com/selecteg12/alfa-automl-hackathon.git
cd alfa-automl-hackathon
```

Доступ к приватному репозиторию нужен до клонирования. Если работаешь через агента, убедись, что ему доступен тот же репозиторий и нужная ветка.

Прочитать README.md и свою карточку. baseline и зависимости лежат в reference/. Два task.md и словари доступны в reference/public_tasks/. CSV скачать по [DATA_SETUP.md](DATA_SETUP.md).

Рабочий solution.py ещё нужно реализовать. Примеры названий будущих отчётов и интерфейсов в задачах — ожидаемые результаты, а не существующая реализация.

## 4. Подтвердить ближайший результат

Сообщить PM: «Беру Sxx / #N, к сроку из карточки передам конкретный результат, блокер такой-то или отсутствует». Перевести карточку в «В работе». Сроки уже заданы датой и временем по МСК; финал — 25.10.2026 20:00.

## 5. Передать задачу агенту

Скопировать Issue целиком и использовать [шаблон запроса](AGENT_TASK_PROMPT.md). Не предполагать, что агент автоматически видит браузер, Drive или локальные CSV: проверить доступность входных материалов.

## 6. Передать проверенный результат

Ссылка на коммит/PR, команда, фактический вывод и ограничения. Перевести в «На проверке». Иван принимает технические изменения, PM проверяет комплектность сдачи. После приёмки карточка становится «Готово».
