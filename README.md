# Альфа Хакатон — автономный ML-агент

Рабочее пространство команды: цели, материалы, задачи и код решения.

**Ближайшая цель:** один общий запуск читает task.md, самостоятельно решает обе публичные задачи и создаёт корректный submission.csv. После этого улучшаем качество и универсальность для новых задач.

## С чего начать

**Старт команды: 23 октября 2026 в 20:00 МСК. Финальное решение: 25 октября в 20:00 МСК.**

Начать с [порядка выполнения](docs/EXECUTION_ORDER.md): там общий график и личный маршрут каждого. Для участника без подготовки: [пошаговый старт](docs/GETTING_STARTED.md). У каждой рабочей карточки есть результат, четыре шага, материалы, зависимости и точный срок.

1. Прочитать [материалы и ограничения](docs/MATERIALS.md).
2. Найти свою задачу в [Issues](https://github.com/selecteg12/alfa-automl-hackathon/issues). Имя ответственного и критерии готовности находятся внутри.
3. Согласовать ближайший результат и время; работать по [правилам команды](docs/WORKFLOW.md).
4. Передать на проверку ссылку на код, команду запуска и фактический результат.

Основная техническая работа — у Ивана (14 карточек, около 20 ч) и Юры (11, около 15,5 ч). Егор ведёт проект, инфраструктуру и сдачу (7, около 8,5 ч). Артём делает EDA, сверку требований и описание результата (6, около 9,5 ч); Максим повторяет готовые команды, проверяет архив и собирает ошибки (6, около 7,5 ч). Оценки относятся к активной работе и уточняются по ходу.
