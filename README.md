# Альфа Хакатон — автономный ML-агент

Рабочее пространство команды: цели, материалы, задачи и код решения.

**Ближайшая цель:** один общий запуск читает task.md, самостоятельно решает обе публичные задачи и создаёт корректный submission.csv. После этого улучшаем качество и универсальность для новых задач.

## С чего начать

Для участника без подготовки: [пошаговый старт](docs/GETTING_STARTED.md). У каждой задачи теперь есть отдельное подробное руководство и полный текст в Issue.

1. Прочитать [материалы и ограничения](docs/MATERIALS.md).
2. Найти свою задачу в [Issues](https://github.com/selecteg12/alfa-automl-hackathon/issues). Имя ответственного и критерии готовности находятся внутри.
3. Согласовать ближайший результат и время; работать по [правилам команды](docs/WORKFLOW.md).
4. Передать на проверку ссылку на код, команду запуска и фактический результат.

Основная техническая работа — у Ивана и Юры. Егор ведёт проект, интеграцию и сдачу; Артём и Максим помогают ограниченными проверяемыми задачами.

## Что уже подготовлено

Материалы, исходный baseline и актуальный список зависимостей находятся в reference/. Рабочий агент ещё не реализован. reference/baseline.py — исходник организаторов для изучения интерфейса, без изменений.

Данные скачиваются из общей папки; модели, API-ключи и результаты локальных запусков в Git не добавляются.

Для старта: Иван берёт #1 и готовит #4, Юра начинает #2 и #3, PM снимает блокеры в #7. Вспомогательные задачи Артёма и Максима — #11 и #12. GitHub-логины остальных участников можно привязать после приглашения.

Приватная доска Projects создана: четыре статуса и отдельные виды «Все задачи», «Иван», «Юра». Приглашения участникам сейчас не отправляются.

## Перед первой сдачей

solution.py, актуальный requirements.txt и все необходимые .py-модули должны лежать в корне ZIP. Итоговый submission.csv сохраняется рядом с task.md. Полный чек-лист — в [материалах](docs/MATERIALS.md).
